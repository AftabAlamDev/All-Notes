\section{Executive Summary}
This proposal presents an AI-powered Admission Operating System for CBITSS.
The system automates counselling, voice calls, WhatsApp communication,
lead qualification, appointment scheduling, follow-ups, and CRM reporting.

\section{Objectives}
\begin{itemize}
\item Provide 24/7 admission counselling.
\item Reduce counsellor workload.
\item Increase lead conversion.
\item Improve student experience.
\item Establish CBITSS as an AI-driven institution.
\end{itemize}

\section{Core Features}

\subsection{AI Voice Receptionist}
The AI answers incoming calls, greets students, and captures inquiry details.

Example:
\begin{quote}
``Hello, welcome to CBITSS. How can I help you today?''
\end{quote}

\subsection{Career Counselling}
The AI collects:
\begin{itemize}
\item Education background
\item Interests
\item Budget
\item Career goals
\item Preferred timings
\end{itemize}

It recommends suitable courses.

\subsection{FAQ Assistant}
Answers questions regarding:
\begin{itemize}
\item Fees
\item Placement assistance
\item Course duration
\item Trainers
\item Certifications
\end{itemize}

\subsection{WhatsApp Automation}
Automatically sends:
\begin{itemize}
\item Brochures
\item Syllabus PDFs
\item Demo schedules
\item Fee details
\item Location details
\end{itemize}

\subsection{Appointment Booking}
Integrates with Google Calendar and Outlook.

\subsection{Follow-Ups}
Automated campaigns:
\begin{itemize}
\item Day 1: Thank-you message
\item Day 3: Demo reminder
\item Day 7: Batch reminder
\item Day 14: Final follow-up
\end{itemize}

\section{Multi-Agent Architecture}

\subsection{Reception Agent}
Handles incoming calls and lead capture.

\subsection{Counselling Agent}
Provides career guidance.

\subsection{Admission Agent}
Explains fees and enrollment.

\subsection{Follow-Up Agent}
Manages reminders and nurturing.

\subsection{Manager Agent}
Provides reports and analytics.

\section{Technology Stack}

\begin{itemize}
\item Backend: Python, FastAPI
\item Workflow: n8n
\item LLMs: OpenAI, Gemini, Claude
\item Voice: Vapi, Retell AI, Twilio
\item Messaging: WhatsApp Business API
\item Database: MySQL, PostgreSQL
\item Vector DB: Qdrant, Chroma, Pinecone
\end{itemize}
